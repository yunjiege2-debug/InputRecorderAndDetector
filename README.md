# Input Recorder & Detector

# Python scripts for mouse and keyboard automation

## About
This is a collection of small Python scripts designed to record and automate simple mouse and keyboard tasks. They are built as basic frameworks, meaning they are easy to modify or expand depending on what you are trying to do.

## What it can do
The project includes four main scripts:

*   **Get mouse coordinates**: Finds and displays the current X and Y position of your cursor on the screen.
*   **Auto-clicker**: Clicks a specific spot on the screen repeatedly at a set interval.
*   **Keyboard recorder**: Logs the keys you press and saves them for later.
*   **Text looper**: Automatically types out a specific string or a list of strings in a loop.

## How to use it
Each script is kept simple so you can jump into the code and change things around. Whether you need to adjust the timing, change the trigger keys, or integrate them into a larger project, the logic is straightforward.
